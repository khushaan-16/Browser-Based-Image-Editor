# 🎨 Browser-Based Image Editor

A modern browser-based image editor built using **HTML, CSS, and Vanilla JavaScript**. Upload images, apply real-time filters, use creative presets, and download the edited image directly from your browser.

---

## 🌐 Live Demo

**🔗 Live Website:** [https://browserbasedimageeditor.netlify.app/]
---

## ✨ Features

### 📤 Upload Images

* Upload images directly from your device.
* Instant preview using the HTML Canvas API.

### 🎚️ Real-Time Filters

Adjust images with interactive sliders:

* Brightness
* Contrast
* Saturation
* Hue Rotation
* Blur
* Grayscale
* Sepia
* Opacity
* Invert

All filters are applied instantly without page refreshes.

### 🎭 Presets

Apply professional-looking presets with one click:

* Normal
* Drama
* Vintage
* Old School
* Noir
* Warm
* Cool
* Faded
* Cinematic
* Dream
* Retro
* Spooky

### 🔄 Reset Filters

Reset all filter values back to their defaults.

### 💾 Download Images

Download the edited image as a PNG file.

### 📱 Responsive Design

Works across desktop, tablet, and mobile devices.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/khushaan-16/image-editor.git
```

### Navigate to the Project

```bash
cd image-editor
```

### Run the Application

Open `index.html` in your browser.

No additional installation or dependencies are required.
